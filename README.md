# Solar Smart

Projeto front-end estático para simulação, dashboard e gestão de dados de energia solar.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (vanilla, no navegador)
- Bootstrap 5.3.3 (via CDN)
- Google Fonts (Syne e DM Sans)

## Estrutura principal

- index.html
- login.html
- dashboard.html
- simulacao.html
- relatorios.html
- configuracoes.html
- css/style.css

## Como inicializar o projeto

Como este é um projeto estático, você tem duas formas simples de iniciar:

### Opcao 1: abrir direto no navegador

1. Abra o arquivo index.html no navegador.
2. Navegue entre as paginas pelos links e botoes da interface.

### Opcao 2: rodar com servidor local (recomendado)

Usando Python:

1. Abra o terminal na pasta do projeto.
2. Execute:

```bash
python -m http.server 5500
```

3. Acesse no navegador:

```text
http://localhost:5500
```
